# STACKLY — Premium Supply Chain Management Website

A complete 12-page enterprise logistics website built with HTML5, CSS3 and
Vanilla JavaScript (GSAP + AOS for animation). All imagery is real,
royalty-free photography (Unsplash / Pexels / Pixabay), optimized to WebP.

## Pages
index.html, about.html, services.html, pricing.html, blog.html, faq.html,
contact.html, login.html, register.html, dashboard.html,
seller-dashboard.html, 404.html

## Structure
css/  style.css · responsive.css · animations.css · dashboard.css · pages.css · mobile.css
js/   navigation.js · main.js · animations.js · interactions.js · auth.js · dashboard.js
img/  10 optimized WebP photos (real photography) · svg/  6 original SVG assets

## Mobile
A dedicated mobile layer (css/mobile.css) reworks the header, hero, cards,
timeline, pricing table, auth screens, dashboards and footer for 320–768px.
Desktop layouts and animations are unchanged.

## Run
Open index.html in a browser, or serve the folder with any static server.
Demo project — forms, logins and dashboard data are front-end demos.
External CDNs: Google Fonts (Inter), GSAP, ScrollTrigger, AOS.
